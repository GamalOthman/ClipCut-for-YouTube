# Screenshots

The main README shows `scissors-menu.png` and `popup.png`; the others are optional extras. Save them here with exactly these names (PNG, about 1200 px wide or less):

| File | What to capture |
|---|---|
| `scissors-menu.png` | A YouTube video with the scissors menu open (Mark start / Mark end / Download clip) and the yellow band on the progress bar. |
| `popup.png` | The toolbar drop-down with marks set and a download in progress. |
| `notification.png` (optional, not used yet) | The Windows "Clip saved" notification. |
| `settings.png` (optional, not used yet) | The ClipCut Settings page. |
| `demo.gif` (optional, not used yet) | A short recording: mark start, mark end, download. |

Before uploading, make sure no personal information is visible: account picture, channel name, e-mail, notifications or other tabs.
